## 4. 复现环境与方法

- 硬件：CPU / 内存 / 磁盘（NVMe SSD）型号与数量。
- OS：内核版本（epoll / io_uring）。
- 压测命令：`bench/mq_bench --topic x --threads y --batch z ...`（P1 后补齐参数说明）。
- 方法：预热 → 打点 60s → 取稳定区间；每场景跑 3 次取中位数。
